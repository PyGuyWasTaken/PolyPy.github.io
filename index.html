Build worlds with code.

Real PolyPy code

This example builds a small world out of bricks and prints what happened.

world.polypy 
# Create a tiny brick world
let world = "Brick Town"
let bricks = 24

func build_wall(amount) {
  let built = 0

  while built < amount {
    built = built + 1
  }

  print("Built" + built + "bricks in" + world)
}

build_wall(bricks)

Install and run

PolyPy scripts use the .polypy extension and run with the native polypy command.

Terminal 
# Install PolyPy
$ pip install polypy

# Run a PolyPy script
$ polypy hello.polypy
Welcome to PolyPy, Explorer

# Start the interactive REPL
$ polypy

Conditions

  print("Nice job!")

Loops
